# 综合盈利因子研报原始权重版本：扩展复现协议

## 研究定位

本实验复用项目已经冻结的四个底层子因子、数据时点、股票池、样本划分、横截面处理、收益标签和 RQAlpha 执行规则，只替换最终合成权重。它是既有 2023—2025 样本外结果已被观察后的扩展复现，不是新的首次确认性样本外检验。

项目继续采用既有的重构口径和代理变量；不声称已完成对研报全部 Wind 原始字段的逐字段复现。

## 研报两层融合规则

招商证券研报第 7.2 节的最终名称为“综合盈利因子”。其四个底层子因子是：

1. 线性剥离杠杆后稳定的 ROE；
2. 稳定的 ROIC；
3. 稳定的 RONOA；
4. FCFFIC。

前三项先形成利润表因子汇总：

\[
\text{利润表因子汇总}=\frac{A+B+C}{3}
\]

再与 FCFFIC 融合：

\[
\text{综合盈利因子}=0.5\times\text{利润表因子汇总}+0.5\times FCFFIC
\]

因此展开后的权重为 `1/6、1/6、1/6、1/2`。程序会逐元素验证两层公式与展开公式一致。

## 不变项与唯一变化项

不变项包括：动态中证 800 股票池、上市满 252 个交易日、ST/停牌过滤、财务数据时点、TTM/MRQ 口径、严格缺失交集、MAD 去极值、CITIC 2019 一级行业和对数市值中性化、z-score、20 个交易日开盘到开盘标签，以及 RQAlpha 的成本和成交约束。

为保证与历史对照可比，组合后沿用既有的一次中性化处理；不在原流程之外增加新的中性化或其他处理步骤。

唯一实质变化为最终合成权重。历史结果称为“等权合成对照版本”（四项各 25%）；本实验称为“研报原始权重版本”。

## 有效样本起点

脚本会保留所有历史信号日的覆盖率审计，但只有四个子因子、股票池掩码、行业分类和市值字段同时可用且可完成中性化的月份，才进入有效因子样本。当前冻结缓存的预期有效样本从 2019 年下半年开始；2016 年至有效样本起点前的月份将标记为 `insufficient_coverage`，不作为失败处理，也不进入 IC、HAC 或分组收益统计。有效样本开始后的任何构建失败仍会中止程序。

## 运行顺序

1. 在 RiceQuant Python 3.9 内核运行 `scripts/11_source_weight_prepare.py`，或运行 [Notebook 11](../notebooks/11_source_weight_composite_replication.ipynb) 的 11.1；
2. 切换至 Python 3.6 / RQAlpha 内核，按 `base_q5`、`base_q1`、`base_equal`、`forced_q5`、`forced_q1`、`forced_equal` 的顺序分别运行 11.2 的六个单组单元；每组完成即保存私有结果，已完成组可断点复用；
3. 切回 Python 3.9 运行 11.3，导出聚合表、图表和最终状态。

这一区分是为了绕过 RQAlpha 原始对象和 pandas 跨版本 pickle 的兼容性限制。中间权重和回测对象仅保存在 `data/` 与 `cache/`，使用 protocol-4 的可移植中间文件在两个内核之间传递。

## 本次运行结果

本次扩展复现已完成。严格样本外 2023—2025 共 36 个月度观测，平均 RankIC 为 `0.011363`，HAC p 值为 `0.479589`；平均 Q5-Q1 月度收益为 `0.364187%`，HAC p 值为 `0.429974`。

RQAlpha 三组合使用相同的 1 亿元初始资金、CSI 800 基准、成本和成交约束。Q5 的回测汇总累计收益为 `35.902%`。在追加 20 个真实交易日的零权重清仓窗口后，Q5 相对 Q1 的逐日净值比值收益为 `13.577%`，相对可投资股票池等权基准组合为 `6.196%`。三个组合的最终股票市值均为零。

这些结果是样本外结果已经被观察后进行的权重口径扩展，不作为首次确认性样本外检验。

## 结论规则

只有同时满足下列条件，才讨论独立 Alpha：

- 严格样本外平均 RankIC 为正，且 HAC p 值小于 5%；
- 严格样本外平均 Q5-Q1 为正，且 HAC p 值小于 5%；
- 追加 20 个真实交易日零权重清仓窗口后，Q5 相对可投资股票池等权基准组合的逐日净值比值收益为正；
- Q5、Q1 和可投资股票池等权基准组合的期末市值均为零。

其他情况的状态为 `candidate_not_confirmed`。不会根据本次结果再次调整权重、持有期、阈值或股票池。

本次结果满足强制清仓后的相对等权可投资股票池正收益条件，但未满足 RankIC 和 Q5-Q1 的完整样本外 HAC 显著性条件。因此最终状态为 `candidate_not_confirmed`。
